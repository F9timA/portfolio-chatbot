# Case Study: Personal Design Projects

## Overview
Alongside her larger case studies, Fatima has designed a range of personal projects that show breadth across industries and design problems — from e-commerce to landing pages to mobile apps. These were self-directed design exercises, used to practice different visual styles, layout systems, and design goals rather than client work.

## Personal Portfolio Website
Fatima designed the complete UI for her own portfolio website in Figma, from the ground up. This included wireframes, an overall layout structure, and a consistent visual system carried across every page. The focus throughout was on clean navigation and responsive layout planning, ensuring the design would hold up cleanly across screen sizes rather than being designed for desktop alone.

**Design focus:** navigation clarity, visual consistency, responsive planning.

## Calligo (E-commerce Concept)
Calligo is a concept e-commerce website for selling calligraphy and paintings. Fatima chose a minimal, warm, sandy color palette specifically because it needed to feel comfortable to look at for extended periods (as an e-commerce browsing experience does) while also complementing the artwork being sold rather than competing with it visually.

**Design focus:** color palette selection tied to product category, minimal layout to keep visual focus on the artwork.

## Noventra (Landing Page)
A landing page design using corporate, professional colors and typography, aimed at a business/corporate audience. This project was an exercise in adapting visual tone — moving away from the warmer, more personal palettes used in projects like Calligo toward something that reads as trustworthy and professional for a business context.

**Design focus:** typography and color as tools for setting audience-appropriate tone.

## Next Music Player (Mobile App)
A mobile application design for a music player, designed with a unique, matching color palette and typography chosen to create a cohesive visual identity throughout the app.

**Design focus:** cohesive visual identity across multiple app screens.

## Craigslist Redesign (Ongoing)
An ongoing redesign of Craigslist's notoriously cluttered, dated interface into a clean, modern layout in Figma. Fatima created wireframes, high-fidelity UI screens, and before/after comparisons to clearly demonstrate the improvement. The redesign focuses on establishing visual hierarchy, consistent spacing, improved typography, and responsive grid systems — addressing the core usability problems with the original site's chaotic, unstructured layout.

**Design focus:** visual hierarchy, information density reduction, responsive grid design.

## Why These Projects Matter
Together, these projects show Fatima's range: she can adapt her visual language to fit very different contexts — from a warm artisanal e-commerce brand, to a corporate landing page, to a utility-focused redesign of a notoriously messy real-world site. This breadth of self-directed practice complements her larger, more technically involved projects (AI UX Critic, Safar, DIAGEN) by showing consistent design fundamentals across many different problem types.
